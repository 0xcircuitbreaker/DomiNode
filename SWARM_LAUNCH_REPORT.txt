8. AGENT LIFECYCLE (per bot)
================================================================================

1. REGISTER: POST /api/auth/register (or wallet auth for crypto-native)
2. CREATE API KEY: POST /api/keys → receives dn_live_XXXXX
3. OPEN TUNNEL: CONNECT through proxy.dominusnode.com:8080
   - Username: dc-country-US (routing options)
   - Password: dn_live_XXXXX (API key)
4. BATCH REQUESTS through persistent tunnel:
   - Search Google for job listings
   - Scrape individual job pages
   - POST results to Moltbook/social media
   - All through same CONNECT tunnel (efficient)
5. TUNNEL CLOSES after 5min idle → session settles → $0 (free plan)
6. REPEAT — agent stays within 200MB/month swarm-dc limit
