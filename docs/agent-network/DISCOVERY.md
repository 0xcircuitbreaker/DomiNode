# Agent discovery on the public site

The public site (`packages/frontend`, served at `VITE_PUBLIC_ORIGIN`) publishes these files so agents, crawlers and registries can find DominusNode. They are generated by `packages/frontend/discovery/generate.mjs` from one manifest (the `DOCS` list) and the hand-written `public/docs/*.md` pages; the Vite build rewrites them for the configured origin. Conventions checked 2026-11-07.

| File | Convention | Status |
|---|---|---|
| `/llms.txt` | llms.txt: H1, blockquote summary, H2 sections of links to markdown | Implemented |
| `/llms-full.txt` | Common companion to llms.txt: all key docs in one file | Implemented (agents, payments, policy, API, MCP, nodes) |
| `/docs/*.md` | llms.txt recommends markdown versions of pages | Implemented |
| `/robots.txt` | RFC 9309; named AI crawler tokens (GPTBot, OAI-SearchBot, ClaudeBot, Claude-SearchBot, PerplexityBot, Google-Extended, CCBot, Applebot-Extended, ...) explicitly allowed; `/admin` and auth pages disallowed | Implemented |
| `/sitemap.xml` | sitemaps.org 0.9 | Implemented |
| `/.well-known/mcp/server.json` | MCP Registry `server.json` (npm package `@dominusnode/mcp-server`, stdio). Serving it under `/.well-known/mcp/` follows the registry auto-discovery pattern Replicate documented; MCP "server cards" (SEP-2127) and IETF `/.well-known/mcp-server` drafts are still unsettled, so no server card is published | Implemented (registry format) |
| OpenGraph, Twitter card, JSON-LD | schema.org `SoftwareApplication` + `Organization` (Daedalus Development Group) in `index.html` | Implemented |
| `<meta name="robots" content="noindex">` | Added at runtime on `/admin` and auth routes, plus `X-Robots-Tag` in host config | Implemented |

## Skipped, and why

- **`/.well-known/ai-plugin.json`**: the OpenAI ChatGPT plugin manifest. ChatGPT plugins were retired in 2024 in favour of GPTs and later MCP/apps, so no current client reads it.
- **A2A agent card (`/.well-known/agent-card.json`)**: describes an A2A *agent* that accepts tasks over the A2A protocol. DominusNode is an API and proxy network, not an A2A agent, so a card would be misleading. Revisit if an A2A endpoint is ever built.
- **x402 discovery**: x402 resources are discovered through a facilitator's discovery listing (the "Bazaar"), not a file on the site, and the gateway already advertises payment requirements in its 402 response. Listing the gateway is an operator task with the chosen facilitator.
- **agents.json**: no widely adopted specification.
