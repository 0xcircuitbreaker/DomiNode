### dominusnode_node_list
Relay nodes you contribute (status, observed IP class, last seen). Contributing IPs earns credit.

args:
- limit (integer, optional): Maximum number of items.
- offset (integer, optional): Items to skip.
usage:
~~~json
{
    "thoughts": [
        "I should use dominusnode_node_list."
    ],
    "headline": "Relay nodes you contribute (status, observed IP class, last seen)",
    "tool_name": "dominusnode_node_list",
    "tool_args": {}
}
~~~
